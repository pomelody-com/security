# Pomelody Security

Welcome to the official security reporting repository for Pomelody.

We take the security and privacy of our users seriously.

## 🔒 Report a Security Vulnerability

If you have discovered a security vulnerability in any
Pomelody product or service, please report it privately.

### [🔐 Report a Vulnerability](https://github.com/pomelody-com/security/security/advisories/new)

All reports submitted through this form are private
and accessible only to authorized maintainers and
the reporter.

## Products Covered

- Pomelody mobile applications (iOS and Android)
- Pomelody Special Needs
- Pomelody websites and online store
- Pomelody APIs and backend services
- Authentication and user data security

## Responsible Disclosure

Please do not publicly disclose vulnerabilities before
we have had an opportunity to investigate and resolve them.

For more information, see our [Security Policy](SECURITY.md).

---

Thank you for helping us keep Pomelody safe!
